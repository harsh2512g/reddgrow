## Extension review

The Manifest V3 source uses `sidePanel`, `storage`, `activeTab` and `scripting`. It does not request history, cookies, permanent Reddit host access, broad host wildcards or external messaging. Temporary active-tab permission supplies the user-invoked composer access; this is narrower than the specification's optional static Reddit host permissions.

| Requirement                        | Source evidence                                                       | Verification boundary                                                                                                                                                                                                                                                                |
| ---------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| One-time connect and revoke        | `background/api.ts`, `background/controller.ts`, web extension routes | Short-lived code exchange, scoped revocable token, disconnect and role re-checking. No Supabase service key is delivered to the extension.                                                                                                                                           |
| Explicit current-tab lookup        | `background/controller.ts`, `shared/messages.ts`                      | Reads the tab URL only after a user command. No navigation observer/background browsing history collection.                                                                                                                                                                          |
| Evidence/risk and current approval | `sidepanel/panel.ts`, private extension RPCs                          | Shows matched opportunity, rule warnings, sources and approved version. Stale versions and revoked roles fail at the server.                                                                                                                                                         |
| Local editing                      | panel and save route                                                  | Local edits disable approved handoff until saved, reverified and approved. The extension cannot approve its own edits.                                                                                                                                                               |
| Insert/copy                        | `content/insert-composer.ts`, controller                              | Explicit user command, supported textarea/contenteditable/open-shadow composer, input events and clipboard fallback. No final-submit click, form submission, synthetic human typing, voting or messages.                                                                             |
| Manual publication receipt         | panel and published route                                             | Explicit confirmation and a validated same-discussion comment permalink. This records the person's action; it never sends a Reddit comment.                                                                                                                                          |
| Credential boundary                | trusted sender validation, extension storage                          | Tokens remain in background storage; neither the panel view model nor injected composer function receives them.                                                                                                                                                                      |
| Real browser compatibility         | extension unit tests and `tests/extension/*`                          | Current MV3 browser run passed connection, edits/reapproval, insertion with zero submissions, copy, manual-publication receipt and revocation. This verifies the local artifact; live Reddit DOM/native-toolbar compatibility and Web Store approval remain separate release checks. |
